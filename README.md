# Class IV Mathematics — Exam Prep

A Gradio webapp for textbook-based exam preparation.

## Chapters
3 Fractions · 4 Decimals · 5 Addition & Subtraction · 6 Multiplication · 9 Geometrical Shapes & Solids · 10 Symmetry

## Modes
- Balanced Practice Test: 50 questions
- Exam Prep Test: 30 questions, with preference for harder questions

## Render
Build Command: `pip install -r requirements.txt`
Start Command: `python app.py`
